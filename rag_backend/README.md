\# RAG Backend



\## Setup



This folder contains the Java RAG backend.



\### Requirements



\- Java 17 or later

\- Maven

\- The `multilingual-e5-small` embedding model



\## Embedding Model



The embedding model is \*\*not included in this Git repository\*\* because the ONNX model file is approximately 448 MB and exceeds GitHub's normal 100 MB file-size limit.



The model must be provided separately.



Place the model locally at:



```text

models/multilingual-e5-small/model.onnx
